# Portfolio – Nhập môn Công nghệ số và ứng dụng trí tuệ nhân tạo (INF2501)

## Xuất bản lên GitHub Pages (khoảng 10 phút)

1. Đăng nhập GitHub và tạo repository mới tên `portfolio`, chọn **Public**.
2. Bấm **Add file → Upload files**, kéo toàn bộ nội dung thư mục này vào (gồm `index.html`, `projects.html`, `conclusion.html`, thư mục `projects/` và `assets/`), rồi bấm **Commit changes**.
3. Vào **Settings → Pages**, mục *Build and deployment*, chọn **Deploy from a branch → main → / (root) → Save**.
4. Sau 1–2 phút, website chạy tại `https://<tên-tài-khoản>.github.io/portfolio/`. Mở bằng cửa sổ ẩn danh để chắc chắn ai cũng xem được mà không cần đăng nhập.

## Trước khi nộp

- Thay mọi phần **tô vàng** (thông tin cá nhân, phần tự viết, ảnh minh chứng).
- Ảnh đại diện: thay `assets/img/avatar.svg` bằng ảnh thật, rồi sửa đường dẫn trong `index.html`.
- Ảnh minh chứng: chép vào `assets/img/`, thay các khung nét đứt trong trang Bài 1, 2, 4.
- Không chỉnh sửa website sau hạn nộp. Lịch sử commit của GitHub ghi lại mọi lần cập nhật.
